# Corvin Develop

Official website and public resources for Corvin Develop applications.

## Local preview

You can open `index.html` directly, or run a simple local web server:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Structure

- `/` — Corvin Develop website
- `/relmuru/` — Relmuru product/support page
- `/relmuru/privacy/` — Relmuru privacy policy (English, Microsoft Store ready)
- `/miragefold/` — MirageFold product page
- `/miragefold/privacy/` — MirageFold privacy policy
- `/bluepill/` — BluePill product page
- `/bluepill/privacy/` — BluePill privacy policy
- `/redpill/` — RedPill product page
- `/redpill/privacy/` — RedPill privacy policy
- `/fapometer/privacy/` — Fapometer privacy policy
- `/app-ads.txt` — will be added before AdMob verification
