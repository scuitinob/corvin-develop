# Corvin Develop

Official website and public resources for Corvin Develop applications.

## Local preview

You can open `index.html` directly, or run a simple local web server:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Structure

- `/` — Corvin Develop website
- `/fapometer/privacy/` — Fapometer privacy policy
- `/app-ads.txt` — will be added before AdMob verification
